# Glosario y voz para la traducción EN (todas las superficies)

## Voz
Mismo registro que el ES: afilado, editorial, directo, cero corporativismo.
"Tuteo" → "you", frases cortas, nada de "we are pleased to".

## Marca
- B2C: "Discoolver" (mayúscula) · 360: "discoolver" y "discoolver 360" (minúscula SIEMPRE)
- Productos con nombre propio NO se traducen: Cool Map, Plan My Trip, Smart
  Calendar, Local Buddy, Business Intelligence, Marketplace.

## Términos canónicos
- sitios → places · fichas → listings · guía → guide · edición → edition
- "Edición 2026" → "2026 Edition" · creador → creator · curador → curator (solo en badge)
- destino (B2B) → destination · alojamiento → accommodation (vertical) / property (establecimiento)
- patronato/DMO → tourism board / DMO · señalética → signage · tótems → interactive kiosks
- punto de venta / POS → point of sale (POS) · cuadro de mando → dashboard
- lista de lanzamiento → launch list · "Avísame" → "Notify me"
- "sin rankings de pago" → "no paid rankings" · comercio local → local businesses

## Reglas duras
- Los campos cuyo valor empieza por "[PENDIENTE" se copian EN ESPAÑOL TAL CUAL
  (son notas internas, no copy).
- Precios, €, teléfonos, emails, URLs y hrefs: intactos.
- Fechas: "1 de septiembre" → "September 1" · "otoño 2026" → "autumn 2026".
- Ciudades: Madrid, Barcelona, Ibiza, Málaga, Ronda, Aranjuez, Bangkok igual;
  "Santo Domingo"/"Punta Cana" igual.
- Ninguna cifra del reparto con creadores (igual que en ES).
- La cita de Ronda se traduce y mantiene la atribución: — Ronda Tourism Board… NO:
  mantener "— Turismo de Ronda" como nombre propio.
