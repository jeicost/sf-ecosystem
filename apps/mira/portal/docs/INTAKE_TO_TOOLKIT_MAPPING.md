## 🔄 Flujo Completo: De Intake a Informes

```
1. Usuario completa Intake Form (15-20 min)
   ↓
2. Sistema analiza respuestas con Claude (vision + structured output)
   ↓
3. Extrae datos clave en formato estructurado:
   - brand_name, industry, stage, size, revenue
   - problem, solution, differentiation
   - target_personas, channels, tnc
   - competitors, competitive_advantages
   - business_model, metrics, runway
   - strategy_so_far, goals_90day
   - resources, constraints
   - brand_tone, content_pillars
   ↓
4. Para CADA informe:
   - SEO Audit: analiza keywords, competencia, gaps
   - Marketing Audit: estrategia por canal, presupuesto
   - Competitive Analysis: benchmarks, white space
   - Investor Deck: narrative + data points
   - Brandbook: identidad visual + verbal
   - Content Strategy: pillars + calendar
   - Action Plan: 30/60/90 roadmap
   ↓
5. Genera 7 informes en PDF + comparte con cliente
   ↓
6. Cliente usa informes + action plan para ejecutar
   ↓
7. (Opcional) Sesión de follow-up para clarificar, ajustar, profundizar
```

## 💡 Tips para Extraer Máximo Valor

### Durante la entrevista (si es sync):
- Profundiza en respuestas cortas: "¿Qué específicamente?"
- Pide ejemplos concretos: "¿Un cliente típico sería...?"
- Desafía supuestos: "¿Estás seguro? ¿Cómo lo sabes?"
- Toma notas de lenguaje (cómo hablan del producto)

### Después de rellenar el form:
- [ ] Verifica datos: ¿números tienen sentido? ¿coherencia entre respuestas?
- [ ] Identifica gaps: ¿qué no respondió? ¿por qué?
- [ ] Busca contradicciones: "dice X pero también dice Y"
- [ ] Propón hipótesis: "Parece que Y es tu verdadero problema, ¿es así?"

### Cuando generes los informes:
- [ ] Personaliza (menciona su nombre, su contexto, no genérico)
- [ ] Sé específico (números, ejemplos de su industria, sus competidores)
- [ ] Prioriza (no todo es igual — identifica top 3 acciones)
- [ ] Sé realista (recomendaciones que pueden ejecutar con sus recursos)
