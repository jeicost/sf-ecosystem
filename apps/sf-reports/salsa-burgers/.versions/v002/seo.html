01ON-PAGE SEO
ElementoEstadoAnálisis
Title tag ⚠ LARGO
Salsa Burgers Bangkok — Premium Wagyu Burgers & 16 Artisan Sauces
69 caracteres — se trunca en SERPs (Google muestra ~60). Los últimos 9 chars desaparecen: pierde "Artisan Sauces" que es una keyword de diferenciación.
Fix: "Salsa Burgers Bangkok | Wagyu Burger Delivery" — 46 chars, keyword + brand + intent
Meta description ✓ OK 137 caracteres. Contiene keywords clave (Wagyu, artisan sauces, Grab, LINE MAN). Meta description bien construida aunque podría añadir un CTA más directo ("Order now" / "30 min delivery").
H1 — CRÍTICO ✗ FALLA
DIP NOW THINK LATER
Es el tagline de marca. No contiene ninguna keyword de búsqueda. Google usa el H1 como señal de relevancia primaria. Un usuario buscando "burger Bangkok" o "wagyu delivery" no ve correlación. Es el factor de ranking más fácil de mejorar con mayor impacto.
Opción A (sin cambiar visual): Añadir visually-hidden H1 con CSS sr-only: "Premium Wagyu Burgers Bangkok — Delivery 30 min"
Opción B: Mover tagline a span decorativo, H1 = keyword real.
H2 / Estructura ⚠ ACEPTABLE H2s incluyen: "PREMIUM WAGYU BURGERS", "SALSA MENU", "IT ALL STARTS WITH THE SAUCE". Parcialmente útiles. Falta H2 explícito sobre delivery o Bangkok para reforzar intención local.
Imágenes / Alt text ✓ PERFECTO 20/20 imágenes tienen alt text descriptivo. Excelente para accesibilidad, Google Images y señales de relevancia temática.
URL estructura ✓ OK URLs limpias con guiones: /menu, /about, /contact, /blog/[slug]. Correctas y rastreables.
Canonical ✓ OK Self-canonical → https://www.salsaburgers.com. Previene duplicación de contenido www vs non-www.
